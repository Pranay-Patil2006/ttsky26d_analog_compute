## How it works

The `tt_um_ttsky26d_analog_compute` is an open-source analog computing ASIC fabricated in SkyWater 130nm CMOS (`sky130A`). The circuit continuously computes a programmable quadratic polynomial function in the analog domain:

$$V_{out} = V_{ref} + R \cdot \left( I_c + I_b \cdot \frac{I_x^2}{I_y} + I_a \cdot I_x \right)$$

where:
- **Voltage-to-Current Converter ($V \to I$):** Converts input voltage $V_{in}$ (`ua[3]`) into a signal current $I_x$ using an OTA-stabilized degenerated PMOS differential architecture.
- **Translinear Core:** Employs MOS translinear loops in weak/moderate inversion to compute linear and squaring functions ($I_x^2 / I_y$), biased by gate reference $V_{t0}$ (`ua[5]`).
- **Digitally Controlled IDACs:** Three 4-bit binary-weighted current DACs control the linear gain $k_1$ (code $a$, `ui[3:0]`), quadratic gain $k_2$ (code $b$, `ui[7:4]`), and DC offset $k_0$ (code $c$, `uio[3:0]`). Note: IDAC inputs are **active-low** ($0 = \text{bit ON}$, $1 = \text{bit OFF}$).
- **Transimpedance Amplifier ($I \to V$):** Converts the summed translinear output current back to voltage $V_{out}$ (`ua[2]`) referenced to the internal on-chip reference voltage $V_{ref} \approx 0.48\,\text{V}$ generated by an on-chip beta-multiplier reference (`MN_TAIL_BIAS`).

### Power Domains & Isolated Measurement Architecture
To enable precise power characterization of the analog compute core without interference from auxiliary circuits, power domains are partitioned across dedicated pins (1.8V-only design, `uses_vapwr: false`, VAPWR not used/not present):
- `VDPWR`: 1.8V supply for auxiliary circuits (both OTAs in V_I and I_V_conv, V_I input mirror, bias tree generating MN_TAIL_BIAS and IDAC branch bias).
- `VGND`: Common ground for auxiliary circuits, IDAC internal mirrors, core output stage, and all NMOS bodies (p-substrate).
- `ua[0]` (`vdd_idac`): 1.8V supply for the three IDACs only, I(ua[0]) measures IDAC power.
- `ua[1]` (`vdd_comp`): 1.8V supply for the translinear compute core (loop diodes and core output mirrors), I(ua[1]) measures core supply power.
- `ua[2]` (`out`): out (Vout).
- `ua[3]` (`in`): in (Vin 0.1-0.7V).
- `ua[4]` (`gnd_comp`): return of the translinear loop only, I(ua[4]) = total compute loop current.
- `ua[5]` (`vt0`): vt0 (~0.7V gate bias).
- `VAPWR`: Not used / not present (`uses_vapwr: false`).

## How to test

### Recommended Equipment
- Multi-channel DC power supply:
  - 1.8V for `VDPWR`, `ua[0]` (`vdd_idac`), and `ua[1]` (`vdd_comp`).
  - 0.70V for `ua[5]` (`vt0`).
- Low-noise DC voltage source / function generator ($0.1\,\text{V}$ to $0.7\,\text{V}$ for `ua[3]` `in`).
- Digital multimeter (DMM) / oscilloscope for `ua[2]` (`out`).
- Current meter / precision ammeter in series with `ua[1]` (`vdd_comp`) to measure core power (and `ua[0]` to measure IDAC power).
- Digital pattern generator or DIP switches on TT demo board for `ui` and `uio`.

### Testing Procedure
1. **Power-up:**
   - Connect `VGND` and `ua[4]` (`gnd_comp`) to ground.
   - Apply 1.8V to `VDPWR`, `ua[0]` (`vdd_idac`), and `ua[1]` (`vdd_comp`).
2. **Bias Reference:**
   - Apply $V_{t0} = 0.70\,\text{V}$ to `ua[5]`.
3. **Set Default Digital Codes:**
   - Linear gain: `ui[3:0] = 0000` (all bits active).
   - Squarer denominator: `ui[7:4] = 0000` (nominal).
   - Offset: `uio[3:0] = 1111` (offset DAC off).
4. **Sweep Input:**
   - Apply a slow DC sweep or ramp on `ua[3]` (`in`) from $0.1\,\text{V}$ to $0.7\,\text{V}$.
5. **Observe Polynomial Output:**
   - Measure `ua[2]` (`out`). Output should smoothly increase from $\approx 0.60\,\text{V}$ to $\approx 1.48\,\text{V}$ with an upward quadratic curvature ($k_1 \approx 1.07$, $k_2 \approx 0.50$; post-layout simulation 0.600 V → 1.477 V).
6. **Measure Core Power:**
   - Measure the DC current $I(ua[1])$ through `ua[1]` across the input sweep; core power is $P_{comp} = 1.8\,\text{V} \cdot I(ua[1])$.
7. **Verify Digital Control:**
   - Change `ui[3:0]` from `0000` to `1111` and verify the linear slope $k_1$ attenuates (simulated: $\approx 1.07$ at `0000`, $\approx 0.30$ at `1110`; `1111` was not simulated).
   - Change `uio[3:0]` from `1111` to `0000` and verify output offset $k_0$ shifts up by $\approx 0.27\,\text{V}$ (simulated 0.486 V → 0.754 V). Note: with `uio[3:0]=0000` the output saturates at $\approx 1.64\,\text{V}$ for $V_{in} \gtrsim 0.62\,\text{V}$.
